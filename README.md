# Deepa Rajagopal — Portfolio Website

A responsive, futuristic portfolio starter with a portrait, neon-glow frame, dark-by-default theme, light/dark switch, subtle 3D movement, scroll reveals, project cards, and a resume starter.

## Files
- `index.html` — main portfolio
- `style.css` — responsive layout, animations, dark/light theme variables
- `script.js` — theme persistence, mobile menu, reveal animations, portrait tilt
- `resume.html` — editable resume starter with Print / Save PDF
- `assets/deepa-profile.jpeg` — supplied portrait

## Run locally
Open `index.html` in a browser. Google Fonts and jQuery load from their CDNs, so an internet connection is needed for those external resources. Core layout and theme styling are local.

## Personalize before publishing
1. Replace `your.email@example.com` in `index.html` with your email address.
2. Update GitHub and LinkedIn links to your own profiles.
3. Replace the illustrative project concepts with real projects and add working demo/repository URLs. Do not present the sample concepts as completed work.
4. Edit the skills and skill indicators to accurately reflect your current abilities.
5. Complete every bracketed field in `resume.html`.
6. Host the folder on GitHub Pages, Netlify, or another static host. Keep the `assets` folder beside the HTML files.

## Theme
The site starts in dark mode. Use the top-right theme switch to change to light mode; the selected theme is saved in the browser when local storage is available.
